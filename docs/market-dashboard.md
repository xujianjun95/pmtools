# 市场看板（本地开发）

页面：`/qdii/dashboard`。桌面 hover「QDII 监控」或按向下键进入子菜单；手机导航中有独立入口。

## 启动

```sh
npm run dev
npm run market:watch
```

第二条命令需在另一个终端运行，每 5 分钟抓取行情。仅刷新一次可运行 `npm run market:refresh`。需要 Python 3.9+，仅使用标准库。页面每分钟重新读取本地缓存；缓存文件不进入 Git。

## 数据口径

报价与近 5 年日线来自 Yahoo Finance chart 接口：道琼斯 `^DJI`、纳斯达克综合 `^IXIC`、标普 500 `^GSPC`、VIX `^VIX`、10 年期美债收益率 `^TNX`、美元指数 `DX-Y.NYB`、美元兑人民币 `CNY=X`；新增恒生 `^HSI`、富时 100 `^FTSE`、DAX `^GDAXI`、日经 225 `^N225`、CAC 40 `^FCHI`。指数保留原标的，没有使用 ETF 或 CFD 代理。

`^TNX` 返回值按收益率百分比展示，变化乘 100 转为基点。其余涨跌以报价时点所在交易日之前的最近有效日线收盘为基准；不使用代表整个查询区间起点的 `chartPreviousClose`。历史走势使用未复权日线点位，最新交易日可能尚未收盘。所有可见时间转换为北京时间。

所有有历史数据的卡片统一使用本地 SVG 绘制最近 30 个交易日日线，美元兑人民币使用 Yahoo Finance `CNY=X`；页面不再加载 TradingView 外部嵌入。底部趋势图仍使用 Yahoo Finance 日线配合 TradingView Lightweight Charts，保留图表内署名链接，支持十字光标、缩放、拖动及明暗主题。


金银使用 Yahoo Finance 的 COMEX 黄金 `GC=F` / 白银 `SI=F` 期货连续报价及日线，单位美元/金衡盎司。页面明确标为期货，不当作伦敦现货；连续走势跨合约时可能受换月影响。涨跌按前一交易日有效日线收盘计算，不标作相对结算价。

铜使用 Yahoo Finance 的 COMEX 铜期货 `HG=F` 连续报价及日线，单位美元/磅（雅虎返回的是美元价格，不能标为美分/磅或美元/吨）。涨跌按前一交易日有效日线收盘计算，不标作相对结算价。页面不再提供 LME 铜现金结算价。

布伦特原油使用 Yahoo Finance `BZ=F` 期货连续报价，单位美元/桶；跨合约走势可能受换月影响，不当作现货或单个固定合约。

## 失败处理与范围

单项失败保留该项原报价、历史与行情时间，标记更新延迟；无旧数据的项显示缺失。全部失败且无缓存时不生成无效文件。输出经过有限数值校验后原子替换；同一输出路径使用文件锁防止重复进程。

页面加载失败可以重试，刷新失败保留已显示数据；缓存超过 15 分钟标记延迟。运行时文件为 `public/qdii/market-dashboard.json`。

此进程与基金限额扫描和邮件通知独立。本次仅提供本地运行入口，没有配置服务器定时任务、开机启动或修改部署流程；上线前需单独安排该数据文件的更新和发布保护。上游访问限流或网络限制仍可能导致更新延迟。
