# 市场看板（本地开发）

页面：`/qdii/dashboard`。桌面 hover「QDII 监控」或按向下键进入子菜单；手机导航中有独立入口。

## 启动

```sh
npm run dev
npm run market:watch
```

第二条命令需在另一个终端运行，每 5 分钟抓取行情。仅刷新一次可运行 `npm run market:refresh`。需要 Python 3.9+，仅使用标准库。页面每分钟重新读取本地缓存；缓存文件不进入 Git。

## 数据口径

当前报价由服务器直接从新浪财经与东方财富抓取，不依赖 Yahoo 或 GitHub 调度。新浪优先覆盖 15 项，东方财富为对应品种的备用源；美国 10 年期国债收益率暂仅使用东方财富。全球指数保留道琼斯、纳斯达克综合、标普 500、恒生、富时 100、DAX、日经 225、CAC 40；东方财富 `100.NDX` 在此接口对应纳斯达克综合，不是纳斯达克 100。

VIX 优先使用新浪 `znb_VIX`、备用东方财富 `167.VIX`；美国 10 年期国债收益率使用 `171.US10Y`，以百分比展示，变化乘 100 转为基点；美元指数优先使用新浪 `DINIW`、备用东方财富 `100.UDI`。指数、收益率及外汇涨跌使用上游昨收基准。全部行情时间转换为北京时间；美股使用明确的交易所 EDT/EST 时间。抓取时间与上游行情时间分开记录，正常休市不会因报价时间较旧而误判抓取失败。东方财富接口实测存在断连，收益率抓取失败时保持旧来源、旧时间与延迟标识。

历史曲线按用户确认的过渡方案保留既有 Yahoo Finance 缓存，不拼接新报价或伪造收盘数据。每项单独记录 `historySource` 与 `historyAsOf`，页面显示曲线来源、截止日期及历史暂不刷新的提示。卡片为最近 30 个缓存交易日，底部趋势图仍使用 Lightweight Charts；报价更新不重置缩放。后续接通可靠的国内历史接口需要单独验证。


商品优先使用新浪外盘连续期货 `hf_GC/hf_SI/hf_HG/hf_OIL`。失败时回退同品种东方财富当月连续：黄金 `101.GC00Y`、白银 `101.SI00Y`、铜 `101.HG00Y`、布伦特 `112.B00Y`，不使用伦敦现货替代。

金银以美元/金衡盎司、铜以美元/磅、布伦特以美元/桶展示。新浪铜报价以美分/磅返回，价格及前结算价同时除以 100；东方财富 `fltt=2` 返回的小数价格不重复缩放。商品涨跌按上游前结算价计算，页面说明此口径，区别于旧版 Yahoo 的前收盘价。连续报价换月可能产生跳变。

美元兑人民币使用新浪 `USDCNY` 在岸参考报价；东方财富 `USDCNYC` 是中间价，不能用于此卡片，也不以离岸 `USDCNH` 替代。在新浪无法取到数据时保留原有效值并标记延迟。

## 失败处理与范围

单项失败保留该项原报价、历史与行情时间，标记更新延迟；无旧数据的项显示缺失。全部抓取失败时保留原文件并返回失败，不生成无效文件。输出经过有限数值校验后原子替换；同一输出路径使用文件锁防止重复进程。

页面加载失败可以重试，刷新失败保留已显示数据；缓存超过 15 分钟标记延迟。运行时文件为 `public/qdii/market-dashboard.json`。

生产由 `market-dashboard.timer` 每 5 分钟启动独立的 `market-dashboard.service`，开机启用并补执行错过的时点。入口为 `/opt/qdii-watcher/fetch_market_dashboard.py --source domestic --out /var/www/pmtools/main/qdii/market-dashboard.json`，依赖同目录 `domestic_market.py`，仅使用 Python 标准库。

查看自动执行：`systemctl list-timers market-dashboard.timer`；查看结果：`journalctl -u market-dashboard.service`；手动刷新：`systemctl start market-dashboard.service`。任务有 240 秒超时，覆盖并发重试预算并短于 5 分钟调度间隔；同一输出路径文件锁防重入、0644 原子发布，全部抓取失败时任务失败且不改输出。前端发布继续保护行情 JSON、锁和临时文件。

`.github/workflows/market-dashboard.yml` 只执行解析与失败保留测试，不定时抓取、不再写入生产。基金限额扫描、邮件通知、数据库和既有服务器任务不参与此流程。公共接口限流或断连仍可能造成单项延迟，不能承诺秒级实时行情。
