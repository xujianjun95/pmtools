# 基金管理改动清单

确认日期：2026-09-26；调整日期：2026-09-28。实施分支：`dev`。本次不包含提交、推送或生产部署。

## 已确认需求

- 后台增加基金管理页，统一管理美国、其他市场、跨市场基金，按标签筛选并支持代码/名称搜索。
- 支持新增、编辑、删除；沿用现有后台管理员权限，不新增角色体系或停用流程。
- 编辑基金维护直销、代销额度及申购状态，三个字段独立切换自动更新 / 手动锁定，保存后统一生效；名称、收益、费率等资料交给扫描器更新。新增时保留名称、市场、地区、类型、标签和可选额度，基金代码唯一且创建后不可修改。
- 直销、代销额度及申购状态支持独立人工锁定。自动模式跟随扫描；手动模式保留人工值。切回自动并保存后恢复最近有效扫描值。底部保存区固定在滚动区域之外。
- 新增流程：输入基金代码、获取资料、预览并补齐、确认添加。不同份额使用各自代码；重复代码拒绝；获取失败允许手动补录。
- 资料优先通过现有 AkShare 相关渠道获取，缺失字段允许现有采集渠道补齐，不把缺失值当作零。
- 前台优先读取 `/background-api/funds` 公开名册，保存后刷新前台即可查看；后台不可用时回退每日扫描 JSON。新增自动进入扫描名单；删除后退出前台和扫描，旧表不再重新导出已删除代码。公开名册不输出内部锁定和自动备份值。

## 实现范围

1. 建立统一基金管理数据与逐字段覆盖规则，兼容既有数据并支持幂等初始化。
2. 增加有鉴权、来源校验和参数校验的管理接口，以及有限时的数据预览获取。
3. 增加基金列表、筛选、编辑和新增预览界面，处理加载、空列表、失败重试、重复提交和删除确认。
4. 接通定时扫描、名单、手动锁定与数据输出，处理扫描和后台同时写入时的一致性。
5. 前台基金名单、分组、筛选数量及统计读取管理结果，覆盖新增和删除。
6. 验证迁移、权限、重复代码、字段校验、锁定/恢复、扫描同步、删除防复活和前台展示。

## 验证边界

- 测试使用临时数据库与输出目录，不修改真实基金库或生产数据。
- 外部数据源实际可用性与页面运行验证分别记录，不把测试桩成功视为真实接口成功。
- 本地完成不代表生产已部署；实际部署需让后台和扫描脚本指向同一管理数据及输出路径。

## 验收场景

| 场景 | 预期 |
| --- | --- |
| 未登录直接请求管理接口 | 返回未授权，不泄露管理数据或允许写入 |
| 录入已存在的六位代码 | 提示重复，不产生第二条基金 |
| 自动预填后仅修改直销额度 | 仅直销额度锁定，其他采集字段仍自动更新 |
| 扫描刷新已锁定基金 | 手工值保留，自动值单独记录；未锁定字段更新 |
| 恢复自动更新 | 使用可用的最新自动值，后续扫描继续更新 |
| 编辑额度为零或清空 | 保留零和空值语义，扫描不会覆盖人工额度 |
| 删除后再次扫描或重启 | 前台及扫描名单不重新出现该基金 |
| 新增不在旧静态清单里的代码 | 进入管理名单、后续扫描和正确前台分组 |
| 新增市场或标签 | 列表筛选与前台分组、数量同步变化 |
| 自动获取失败或超时 | 显示失败原因，保留手动补录入口，不自动创建 |
| 扫描和后台编辑同时发生 | 不丢失手动修改，不导出过时的覆盖结果 |
| 桌面与窄屏管理页面 | 表单可操作，长名称可阅读，操作按钮不被遮挡 |
| 旧库额度 100 元迁移 | 仍为 100 元；仅旧静态种子的万元值需要转换；已初始化库仅修复可由旧扫描表证明的误迁移，不动人工额度 |
| 手动清空字段后锁定 | 下一次扫描保持空值，不使用抓取值重新填回 |
