# PMTOOLS 聚合页 · UI 设计审查报告

> 审查时间：2026-08-15 ｜ 审查方式：源码走查 + Playwright 实际渲染截图（桌面 1440 / 移动 390 / 暗色模式）
> 总体评价：设计系统基础扎实（token 双主题、组件化规范、动效细节丰富），桌面端视觉完成度高。主要问题集中在**移动端适配、可访问性、代码卫生**三个方面。

## P0 · 明确 Bug

### 1. 移动端 Header 导航挤压换行
- **现象**：390px 视口实测 nav 宽度仅 146px，「造物」「资讯」等两字导航竖排断行，顶栏视觉崩溃。
- **位置**：`Header.module.css`（`@media (max-width: 768px)` 只缩小了 gap，没有处理换行）。
- **建议**：移动端将导航收进汉堡菜单，或 `flex-wrap: nowrap` + 横向滚动 + 缩短字距；至少保证单行不换行。

### 2. 死代码：`src/index.css` / `src/App.css`
- **现象**：`main.jsx` 只引入了 `styles/global.css`，这两个文件没有被任何地方引用。且 `index.css` 里是**另一套完全不同的设计系统**（紫色 accent `#aa3bff`、1126px 居中容器、`prefers-color-scheme` 暗色），极易误导后续修改。
- **建议**：直接删除或归档到 `vite-temp/`。

### 3. Finder 重复拷贝文件
- `components/layout/DiaGradient 2.jsx`、`DiaGradient.module 2.css` 是复制产生的冗余文件，带空格和数字的文件名在 import/构建时有隐患。
- **建议**：确认无引用后删除。

## P1 · 可访问性（WCAG）

### 4. `--text-muted` 对比度不达标（AA）
| 主题 | 组合 | 实测对比度 | 要求 |
|---|---|---|---|
| Light | `#8a8478` on `#f7f5f2` | ≈ 3.3:1 | 4.5:1 |
| Dark | `#6a6258` on `#111010` | ≈ 3.1:1 | 4.5:1 |

该色用于 0.66–0.75rem 的小字（状态栏、计数、日期、技术标签），属于最需要达标的场景。建议 light 调至 `#6f6a5e` 左右、dark 调至 `#8f877c` 左右。

### 5. 主题切换 FOUC（闪白）
- `data-theme` 在 `useEffect` 里才写入 `<html>`，暗色用户首帧会先渲染浅色兜底背景再闪黑。
- **建议**：在 `index.html` `<head>` 加一段内联脚本，在首帧绘制前读取 localStorage / 系统偏好并设置 `data-theme`；同时加 `<meta name="color-scheme" content="light dark">`。

### 6. 主导航无键盘焦点可见样式
- `ProjectCard`（`:has(.cardLink:focus-visible)`）和 `ThemeToggle` 都有焦点反馈，唯独 Header 的 Logo / 造物 / 资讯 / 关于我没有 `:focus-visible` 样式，键盘用户 Tab 到导航时完全无感知。
- **建议**：给 `.navLink` / `.logo` 补 `:focus-visible { outline: 2px solid var(--accent); outline-offset: 4px; }`。

### 7. 「文章」入口的禁用态无视觉区分
- 它是 `<span aria-disabled="true">`，但样式与可点击链接完全一致，用户点了没反应会困惑。
- **建议**：降低不透明度 + `cursor: not-allowed`，或加「即将上线」角标/tooltip。

### 8. Modal 焦点管理缺失
- 有 Esc 关闭和遮罩点击关闭（👍），但缺少：打开时焦点移入对话框、Tab 焦点圈禁（focus trap）、关闭后焦点还给触发按钮。
- `NewsItem` 的 `role="button"` 建议补 `aria-expanded={expanded}`。

### 9. 自定义光标的风险兜底
- `cursor: none !important` 全局隐藏系统光标，而自定义光标初始不可见（首次 mousemove 才显示），且完全依赖 JS。JS 异常时用户将没有光标。
- **建议**：给 `.cursor` 初始 `opacity` 加一个延迟兜底动画，或保留系统光标 + 自定义光标作为增强层（跟随环）。

## P2 · 视觉与体验优化

### 10. 中文伪斜体
- Hero 副标题「造点顺手的工具，解决一些小麻烦。」用 `DM Serif Display` + `font-style: italic`，中文字形实际走系统衬线回退并**合成伪斜体**，笔画变形、阅读质量差。
- **建议**：中文部分去掉 italic，用颜色/字重做层次；或改用「宋体+正常字形+字号对比」的编辑排版手法。

### 11. 暗色模式下 Mockup 亮块刺眼
- 各项目 mockup 是亮色烘焙的界面图，在暗色页面里是一块块高亮白块，视觉跳跃感强（实测暗色截图很明显）。
- **建议**：暗色主题下给 mockup 容器加 `filter: brightness(0.85) saturate(0.9)` 过渡，或逐步做暗色变体。

### 12. NewsItem 负 margin 布局 & 移动端信息丢失
- `.meta` / `.expanded` 用 `margin-right: -48px` 补偿 `.body` 的 `padding-right`，属于脆弱 hack；移动端 `.meta { display: none }` 直接丢掉了来源和日期。
- **建议**：改为 grid/flex 正常布局；移动端把来源+日期折到第二行小字展示，而不是隐藏。

### 13. 双动画库并存
- 项目同时依赖 `gsap`（ScrollTrigger）和 `motion`（BlurText）。两者职责可以合并到一个库，减少约 60–80KB 的 bundle。
- **建议**：统一用 motion（或 gsap）实现 BlurText 效果。

### 14. 骨架屏高度与实际卡片不一致
- 骨架条高 64px，实际新闻卡约 100px，加载完成瞬间列表会明显跳动。
- **建议**：骨架高度对齐真实卡片（含 padding），或加 `min-height` 占位。

### 15. 字体跨平台一致性
- `--font-display` 首选 `'New York'` 仅 Apple 平台有，Windows/Android 落到 `Noto Serif SC`/Georgia，标题气质会有明显差异。
- **建议**：如对标题字体有要求，考虑自托管一款衬线字体子集。

## 做得好的地方（保持）

- 双主题 token 体系完整，阴影/边框语义分层清晰
- `prefers-reduced-motion` 覆盖比较全面（hero 动画、卡片过渡都有降级）
- ProjectCard 的 `:has(:focus-visible)` 焦点等效 hover 处理很专业
- NewsItem 有完整的键盘操作（Enter/Space）
- `scroll-margin-top` 与 fixed header 的锚点补偿处理细致
- Hero 黄金分割构造图的交互（弹簧跟随圆点）完成度很高
